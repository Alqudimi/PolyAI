### 💬 GitHub Discussions

For questions, ideas, and general discussion:
**https://github.com/Alqudimi/PolyAI/discussions**

Good for:
- "How do I…?" questions
- Architecture discussions
- Sharing what you've built
- Feature brainstorming

### 🐛 GitHub Issues

For bugs and confirmed problems:
**https://github.com/Alqudimi/PolyAI/issues/new/choose**

Use the appropriate template:
- [Bug Report](https://github.com/Alqudimi/PolyAI/issues/new?template=bug_report.yml)
- [Feature Request](https://github.com/Alqudimi/PolyAI/issues/new?template=feature_request.yml)
- [Question](https://github.com/Alqudimi/PolyAI/issues/new?template=question.yml)

### 🔒 Security Vulnerabilities

**Do NOT use public Issues for security reports.**

See [SECURITY.md](SECURITY.md) for the responsible disclosure process.

## Response Time Expectations

This is an open-source project maintained by [Abdulaziz Alqudimi](https://github.com/Alqudimi). Response times are best-effort:

| Channel | Expected Response |
|---|---|
| Security reports | Within 48 hours |
| Bug reports | Within 1 week |
| Feature requests | Within 2 weeks |
| GitHub Discussions | Best effort |

## Provider Support

PolyAI is a client library. For issues with the AI providers themselves (model quality, account billing, provider downtime), contact the providers directly:

| Provider | Support |
|---|---|
| OVHcloud AI Endpoints | [OVHcloud Support](https://www.ovhcloud.com/en/support/) |
| Pollinations.AI | [Pollinations Discord](https://discord.gg/pollinations) |
| mlvoca | [mlvoca website](https://mlvoca.com) |
| DevToolbox | [DevToolbox website](https://devtoolbox-api.devtoolbox-api.workers.dev) |
