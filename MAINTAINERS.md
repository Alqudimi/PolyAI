## Responsibilities

The lead maintainer is responsible for:

- **Code review** — reviewing and merging pull requests
- **Releases** — publishing new versions to PyPI
- **Security** — responding to security reports (see [SECURITY.md](SECURITY.md))
- **Roadmap** — setting and communicating project direction
- **Community** — enforcing the [Code of Conduct](CODE_OF_CONDUCT.md)
- **CI/CD** — maintaining GitHub Actions workflows

## Becoming a Maintainer

Contributors who make significant, sustained contributions to PolyAI may be invited to become maintainers. There is no formal application process — the lead maintainer extends invitations based on contribution history, code quality, and community engagement.

Maintainer responsibilities include:
- Reviewing PRs promptly (goal: within 7 days)
- Participating in design discussions
- Helping triage issues
